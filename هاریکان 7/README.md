# هاریکان ۷

سورس ربات @Harikan7_bot و Mini App، تا ۱۳ اکتبر ۲۰۲۶.

کد رابط در src، بک‌اند فعال در tgcloud و موتور محاسبات در shared است. server و zk-sync نسخه‌های اولیه‌اند. نصب وابستگی‌ها با npm ci و ساخت با npm run build؛ موتور shared/core.js باید با esbuild در tgcloud/lib/core.js بسته‌بندی شود.

شیفت پیشرفته، ثبت لوکیشن، ثبت کسب‌وکار با مدارک الزامی و کنترل ورود کارمند بر اساس موبایل ثبت‌شده پیاده‌سازی شده‌اند. جداسازی کسب‌وکارها منطقی در دیتابیس مشترک است.

تغییرات لوگوی اختصاصی در سورس موجود است اما ارسال و تأیید لوگو از تلگرام هنوز تکمیل و منتشر نشده است. تبدیل ویس به متن، اتصال جولیو، SLA و شناسایی سخت‌افزار هنوز فعال نیستند. این پوشه نسخهٔ سورس است و به معنی انتشار همهٔ تغییرات روی تلگرام نیست.

توکن‌ها، دیتابیس زنده، مدارک و داده‌های کاربران، node_modules و خروجی کامپایل در این پوشه قرار ندارند. لوگوی آرومین متعلق به همان کسب‌وکار است. راهنمای TELEGRAM-README.md قدیمی است؛ ورود جدید با موبایل تأییدشده جایگزین توضیح قدیمی شناسهٔ تلگرام شده است.

آزمون مرتبط: node --test --test-isolation=none tests/tenant.test.js tests/shifts.test.js tests/advanced-integration.test.js — ۲۵ آزمون پاس شدند.
