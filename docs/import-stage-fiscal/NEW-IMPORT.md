# ایمپورتِ کاملِ تازهٔ Joolio (از 3.9.45)

تصمیمِ کاربر (2026-10-07): دادهٔ ایمپورت‌شدهٔ فعلی پاک و خروجیِ کامل و تازهٔ Joolio دوباره ایمپورت می‌شود.
`fix_stage_dates.py` در مخزن و بسته می‌ماند ولی **اجرا نمی‌شود** (نه dry-run جدید، نه `--apply`) مگر کاربر دوباره بخواهد.

## قرارداد (کد: `frontend/src/engines/deal-import/index.ts`)
| موضوع | قاعده |
|---|---|
| تاریخِ فروش | فقط سلولِ «تغییر مرحله» (`HH:MM:SS YYYY/MM/DD`)؛ روز، ماه و ساعت از همان مقدار |
| سالِ مالی | سالِ شمسیِ همان سلول، فقط اگر در `years` سیستم تعریف شده باشد؛ ستونِ «سال مالی»، «ورود»، نامِ فایل و زمانِ سیستم منبع نیستند؛ هیچ fallback |
| فقط ۱۴۰۵ | ردیف‌های سال‌های دیگر شمرده و گزارش می‌شوند، نوشته نمی‌شوند |
| Audit | مقدارِ خام در `stageChangedAt` هر ردیف ذخیره می‌شود |
| تکراری | همان شماره با همان مشتری، کارشناس، مبلغ و تاریخ → ثبت نمی‌شود (idempotent) |
| تعارض | همان شماره با مشتری/کارشناس/مبلغ/تاریخِ دیگر، یا بیش از یک فاکتورِ هم‌شماره در دفتر، یا دو نسخهٔ ناهمسان در همین فایل → **خودکار تطبیق نمی‌شود**؛ ثبت نمی‌شود، تاریخی تکمیل نمی‌شود، «تعارض» با نامِ فیلد گزارش می‌شود |
| نامِ کارشناسِ ناشناخته | به کارشناسِ مشابه وصل نمی‌شود؛ در پیش‌نمایش «نامِ تازه» علامت می‌خورد (با ثبت، کارشناسِ تازه ساخته می‌شود) |
| یکسان‌سازیِ بی‌ضرر | ارقامِ فارسی/عربی، «ي/ك»، نیم‌فاصله، فاصله، عنوان (آقای/خانم/…) — هیچ تطبیقِ فازی |

## گزارشِ اعتبارسنجی
- **پیش‌نمایش** (مرکز ایمپورت): شمارِ معتبر / سال‌های قبل / تکراری / تعارض / نامعتبر + جدولِ کارشناس × ماه + فهرستِ ردیف‌های کنارگذاشته با علت.
- **importLog**: همان گزارش (`report.bySeller`، `newNames`، `flagged` تا ۳۰۰ ردیف) بدونِ نامِ مشتری.
- **سرور** (فقط خواندن، بدونِ قفل): `python validate_ledger.py --tenant team --json /var/tmp/validate.json` — به تفکیکِ کارشناس و ماه + بررسی‌های تکراریِ فاکتور، مقدارِ خامِ مفقود/نامعتبر، ناهمخوانیِ سال/تاریخ/ماه، و خلاصهٔ آخرین ایمپورت‌ها.

## باز
- پاک‌کردنِ دادهٔ ایمپورت‌شدهٔ فعلی: ابزاری برایش ساخته نشده. «جایگزینیِ فقط ماه‌های فایل» اسنادِ قفل (تصویب‌شده/در انتظار/بسته) را نگه می‌دارد و فقط ردیف‌های قفل‌نشدهٔ همان کارشناس و ماه را عوض می‌کند. نقش‌ها، وزن‌ها و تأییدِ مالیِ ردیف‌های پاک‌شده با ایمپورت برنمی‌گردند.
