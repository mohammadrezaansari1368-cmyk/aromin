Dashboard layouts use `/api/ui-layout`, list `dashboard.widgets`, and `order` entries `id:size`. Tenant comes from `currentTenant()`; Bearer authentication determines the user server-side. Unknown ids/sizes and duplicate widgets are ignored; `mergeLayout` retains role filtering.

An empty server slot reads `/api/state` → `full.dashboardLayout[session.user]` once during loading, then the local cache. Edits write only `/api/ui-layout` after 800 ms. Cache keys contain the JSON tuple `[tenant, user]` (null user for anonymous views), never credentials; the old global cache is not imported. Missing, tokenless or mismatched sessions stay local. Save failures show a Persian status with retry; 401 requests sign-in. Successful saves clear the status. Unmount/session changes cancel pending saves; already in-flight requests may finish.
